Automated Syntax & Semantic Processing Guide

1. Lexical Analysis (Scanning)

The lexer scans the raw character stream and converts it into discrete tokens with line and column tracking using Regular Expressions and Finite Automata. Each token carries its type, lexeme, and source location.

2. Syntax Analysis (Parsing) & AST

Syntax analysis validates if the token sequence adheres to the Context-Free Grammar (CFG). Recursive-descent with predictive parsing generates an Abstract Syntax Tree (AST), stripping away syntactic noise (delimiters, parentheses) and retaining semantic hierarchy.

3. FIRST and FOLLOW Sets

  • FIRST(α): The set of terminals that begin strings derived from α. If α can derive ε, then ε ∈ FIRST(α).
  • FOLLOW(A): The set of terminals that can appear immediately to the right of non-terminal A in some sentential form. For start symbol S, $ ∈ FOLLOW(S).

4. LL(1) Grammar Conditions

A grammar G is LL(1) if and only if whenever A -> α | β are two distinct productions:

  • FIRST(α) ∩ FIRST(β) = ∅ (No First/First conflict)
  • If ε ∈ FIRST(α), then FIRST(β) ∩ FOLLOW(A) = ∅ (No First/Follow conflict)

5. Semantic Analysis & Symbol Tables

Semantic analysis enforces static language invariants that cannot be expressed in context-free grammars:

  • Hierarchical Scope Table: Tracks variables and functions across global, local, and nested block scopes.
  • Type Checking: Validates assignment compatibility, operator legality (e.g. arithmetic on numbers only), and function parameter arity/types.

6. Intermediate Code & Virtual Machine

The compiler translates AST nodes into Three-Address Code (TAC), represented as Quadruples (Op, Arg1, Arg2, Result), partitions TAC into Basic Blocks, and executes it in an interactive step-by-step virtual machine.
